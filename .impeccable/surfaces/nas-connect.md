# NAS 연결

Mode: Operate. Extend the incumbent settings surface without changing its visual system.

User task: provide NAS IP and account, choose a discovered protocol, browse and select a directory without typing share or internal folder names.

Flow: NAS information → protocol radio selection → directory browser and destination confirmation. Preserve back navigation, retryable errors, empty folders, parent/breadcrumb navigation, list filtering and pagination. SMB root is a share chooser; it cannot be connected until a share is opened. Credential inputs remain only in component memory and clear after successful authentication. Root-protected connection files support subsequent scans and server restart.

World: inherit DESIGN.md's Pretendard, neutral dark surfaces, restrained controls, icon system and mobile spacing. No new theme or token system.

Validation: desktop and 390px mobile synthetic captures, real NAS SMB shared-folder listing and read-only mount, automated account/path/credential boundary checks. Parent integrates native build and deployment separately.
