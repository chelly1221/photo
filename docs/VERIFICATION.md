# 검증 기록

## 0.4.0 · 컴팩트 헤더·OpenFreeMap·미디어·백그라운드 (2026-09-14)

- 검색과 갤러리의 보이는 제목을 제거해 기본 헤더를 두 줄로 줄였다. 모바일 기본 헤더 높이 100px, 320px 날짜 필터 확장 시 가로 넘침 없음. 기존 왼쪽 월 연표와 핀치 배열 조절은 유지했다.
- OpenFreeMap Dark/MapLibre 지도, 한국어 확대·축소, 클러스터 사진 목록에서 개별 뷰어로 이동을 확인했다. Leaflet·MapLibre 로고는 표시하지 않고 OpenFreeMap·OpenMapTiles·OSM 데이터 출처는 유지한다.
- 사진·RAW·동영상 77개 확장자 목록을 서버·웹·Android가 공유한다. 서버 코덱으로 합성 샘플 17개 및 CC0 DNG·CR2·NEF 샘플을 변환하고 원본 바이트가 유지됨을 확인했다. 모든 카메라·코덱 조합을 검증했다는 의미는 아니다. 상세 범위는 MEDIA-FORMATS.md 참조.
- 브라우저에서 인증된 청크로 동영상 재생본을 받아 2.02초 샘플이 끝까지 재생되는 것을 확인했다. 콘솔 오류 없음. 서버 API의 인증·음수 offset·범위 초과 및 중첩 폴더 재귀 탐색 테스트 통과.
- NAS 서버의 독립 주기 스캔·실패 재시도, Android 알림을 사용하는 WorkManager 작업·연속 작업·네이티브 설정 복원·사진과 동영상 백업을 반영했다. Android 16 에뮬레이터의 계정 origin·임의 ID 차단·네트워크 제약·연속 작업·형식 관련 테스트 5개 통과. 실제 휴대폰의 화면 꺼짐·재부팅·제조사 절전 중 전송은 별도 확인이 필요하다.
- Vitest 37개, TypeScript·웹·API 빌드, Android 서명 release 빌드 통과. Impeccable 검출 실패 0개; 기존 디자인 문서와 값 차이에 대한 advisory 40개는 별도 문서 정합성 안내로 남았다.
- APK `kr.threechan.photo`, versionName `0.4.0`, versionCode `4`, 13,123,084바이트. 기존 0.3.0과 서명 인증서 일치. SHA-256: `2d005b58a96b5ff3a91caa7f51ae740236bcf364210290787dd3d685c6384d4e`.
- 공개 웹·APK 및 사설 API 배포 완료. 공개 산출물 12개와 APK 다운로드 해시가 로컬 빌드와 일치한다. 공개 사진·연표·동영상 API는 404, 비인증 사설 API는 403이며 Tailscale 계정 인증과 연표 총수 일치를 확인했다. 지도 worker·타일·Blob 재생용 CSP도 확인했다.
- 처음 패키지 폴더 교체는 root 소유권 때문에 실패해 이전 앱으로 자동 복구했고, 해당 디렉터리를 권한 있는 작업으로 교체한 재배포가 성공했다. 이전 산출물·Linux 의존성은 `/srv/photo/.deploy/0.4.0-20260914/previous`, 웹 이미지는 `photo-web:rollback-0.4.0`에 보관했다. NAS 원본·운영 자격 증명 변경 없음.

## 0.2.0 · NAS 탐색 연결 (2026-09-13)

- NAS IP·계정 입력 → 발견된 프로토콜 선택 → 공유/하위 폴더 탐색 → 보관함 연결 UI 구현. 데스크톱과 390px 모바일에서 긴 폴더 이름, 상위 경로, 비활성화 상태, 권한 오류를 합성 데이터로 확인. Impeccable 범위 검토 PASS.
- JavaScript/서버 테스트 12개, Linux Python NAS 브로커 테스트 3개 통과. 검색 결과의 계정 귀속, 인증 전에 자격 증명을 전송하지 않는 동작, 경로 제한, root 전용 설정 파일, 로그인 실패 후 임시 설정 정리, 폴더 페이지 분할 확인.
- 실제 기존 NAS에서 SMB와 SSH 서비스 탐지, SMB 인증, 공유 28개 조회, 하위 폴더 탐색과 읽기 전용 FUSE 마운트 확인. 기존 NAS 계정의 SFTP 로그인/폴더 접근은 성공하지 않았으므로 해당 NAS의 SFTP 권한 설정을 확인해야 함. WebDAV는 해당 NAS에서 활성 서비스가 발견되지 않아 실제 계정으로 검증하지 않음.
- NAS에 별도의 임시 검증 폴더를 만들어 새 GUI 연결 경로를 통한 백업, 원격 파일 바이트 비교, 중복 백업 차단, 사진 인덱싱·썸네일 생성을 확인한 후 테스트 폴더와 마운트 정리. 기존 사진 파일 변경 없음.
- TypeScript·웹·API 빌드 및 Android 0.2.0 서명 release APK 빌드 확인. 실제 휴대폰에서 이 새 연결 흐름을 사용하는 검증은 아직 수행하지 않음.

- Android 서명 release APK 빌드.
- Android 16 에뮬레이터의 네이티브 설정 복원·네트워크 제약, 임의 파일 ID 읽기 차단, 인증 브라우저 origin 제한 테스트.

- Impeccable 검토에서 발견한 백업 설정 초기화, 12장 이후 업로드 진행, 지도 중첩 선택 문제 수정 후 한정 재검토 PASS.

- 공개 웹 및 사설 API 경로 분리, Tailscale Serve 계정 식별, production 서비스 시작 확인.

## 아직 현장에서 확인해야 할 항목

첫 사용자 기기의 내장 Tailscale 승인부터 실제 사진 열기까지 인증을 마친 전체 흐름, 실제 휴대폰의 화면 꺼짐·재부팅·제조사 절전 상태에서 NAS까지 자동 백업되는 흐름은 검증하지 못했습니다. 에뮬레이터 테스트를 실기기 검증으로 간주하지 않습니다.

앱에서 공유 폴더를 연결하고 Android에서 사진·동영상 권한과 백업 대상을 선택한 뒤 소량의 실제 파일로 전송과 NAS 저장 결과를 확인해야 합니다. iOS 백그라운드 자동 백업은 포함하지 않습니다. 0.4.0에서 HEIC 합성 샘플은 검증했지만 모든 코덱·기종의 호환성은 확인하지 않았습니다.
