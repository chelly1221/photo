# 검증 기록

## 0.2.0 · NAS 탐색 연결 (2026-09-13)

- NAS IP·계정 입력 → 발견된 프로토콜 선택 → 공유/하위 폴더 탐색 → 보관함 연결 UI 구현. 데스크톱과 390px 모바일에서 긴 폴더 이름, 상위 경로, 비활성화 상태, 권한 오류를 합성 데이터로 확인. Impeccable 범위 검토 PASS.
- JavaScript/서버 테스트 12개, Linux Python NAS 브로커 테스트 3개 통과. 검색 결과의 계정 귀속, 인증 전에 자격 증명을 전송하지 않는 동작, 경로 제한, root 전용 설정 파일, 로그인 실패 후 임시 설정 정리, 폴더 페이지 분할 확인.
- 실제 기존 NAS에서 SMB와 SSH 서비스 탐지, SMB 인증, 공유 28개 조회, 하위 폴더 탐색과 읽기 전용 FUSE 마운트 확인. 기존 NAS 계정의 SFTP 로그인/폴더 접근은 성공하지 않았으므로 해당 NAS의 SFTP 권한 설정을 확인해야 함. WebDAV는 해당 NAS에서 활성 서비스가 발견되지 않아 실제 계정으로 검증하지 않음.
- NAS에 별도의 임시 검증 폴더를 만들어 새 GUI 연결 경로를 통한 백업, 원격 파일 바이트 비교, 중복 백업 차단, 사진 인덱싱·썸네일 생성을 확인한 후 테스트 폴더와 마운트 정리. 기존 사진 파일 변경 없음.
- TypeScript·웹·API 빌드 및 Android 0.2.0 서명 release APK 빌드 확인. 실제 휴대폰에서 이 새 연결 흐름을 사용하는 검증은 아직 수행하지 않음.

## 확인한 항목

- TypeScript 검사, Vite 웹 및 esbuild API 빌드.
- Go/WASM 내장 Tailscale 빌드 및 브라우저 실행. 공식 Tailscale 로그인 URL 발급 확인.
- Vitest 9개: 허용 계정·origin 제한, 경로 탈출 차단, 실제 썸네일 크기, 즐겨찾기와 캐시 복원, NAS 장애 시 인덱스 보존, 삭제 재조정, 심볼릭 링크 제외, 업로드 오프셋/재개/해시/중복/읽기 전용 보호, 29장 연속 백업, 제한 시간 후 이어가기.
- Android 서명 release APK 빌드.
- Android 16 에뮬레이터의 네이티브 설정 복원·네트워크 제약, 임의 파일 ID 읽기 차단, 인증 브라우저 origin 제한 테스트.
  실행 명령: `android/gradlew -p android :app:connectedDebugAndroidTest` (3개 통과). 서드파티 Capacitor 모듈 자체 테스트는 이 명령의 대상이 아닙니다.
- 합성 이미지 36장으로 데스크톱 및 모바일 사진 목록, 뷰어, 정보 패널, 공유 추가 화면, 지도 확인. 같은 좌표의 서로 다른 사진을 개별 선택하고 올바른 원본 정보가 열리는 것 확인.
- Impeccable 검토에서 발견한 백업 설정 초기화, 12장 이후 업로드 진행, 지도 중첩 선택 문제 수정 후 한정 재검토 PASS.
- 서버의 실제 NAS 공유를 전용 임시 마운트에서 SMB 3.1.1 암호화/읽기 전용으로 연결하고 해제. 원본 파일 변경 없음.
- 공개 웹 및 사설 API 경로 분리, Tailscale Serve 계정 식별, production 서비스 시작 확인.

## 아직 현장에서 확인해야 할 항목

첫 사용자 기기의 내장 Tailscale 승인부터 실제 사진 열기까지 인증을 마친 전체 흐름, 실제 휴대폰의 화면 꺼짐·재부팅·제조사 절전 상태에서 NAS까지 자동 백업되는 흐름은 검증하지 못했습니다. 에뮬레이터 테스트를 실기기 검증으로 간주하지 않습니다.

운영 앱에는 실제 공유 폴더를 미리 등록하지 않았습니다. 앱에서 공유 폴더를 추가하고 Android에서 권한·백업 대상을 선택한 뒤 소량의 실제 사진으로 전송과 NAS 저장 결과를 확인해야 합니다. iOS 백그라운드 자동 백업과 HEIC 미리보기의 코덱별 호환성은 검증 범위에 포함하지 않습니다.
