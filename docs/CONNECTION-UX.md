# 보관함 연결

로그인 화면은 앱의 다크 테마와 Pretendard를 사용하는 `보관함 연결` 화면이다.
`연결하기` 한 번으로 Tailscale 엔진을 시작하고 인증 URL이 준비되면 인증 창을 연다.
계정 인증은 Tailscale 공식 HTTPS 페이지에서 이루어지며, 앱은 연결 준비·인증 대기·취소·오류·재시도 UI를 제공한다.

웹에서는 사용자가 누른 시점에 인증 창을 확보해 비동기 URL 발급으로 인한 팝업 차단을 줄인다.
차단된 경우 `인증 창 열기` 버튼을 제공한다. 인증 창의 opener는 제거한다.
Android는 기존 다크 Custom Tab을 사용하며 수동으로 닫으면 앱에 취소 이벤트를 전달한다.

인증이 끝나 Tailscale이 Running 상태가 되면 기존 앱 진입 로직이 사진 화면을 열고 인증 창을 닫는다.
이미 연결된 기기는 저장된 Tailscale 상태를 재사용한다. 취소 시 해당 시도의 대기 구독과 타이머를 해제한다.
앱 자체에서 계정 비밀번호를 받거나 Tailscale 인증 페이지를 프록시하지 않는다.

로컬 흐름 검증용 페이지는 `.local/connection-preview.html`이며 배포 산출물에는 포함하지 않는다.
Android 실제 기기에서 인증 완료 및 수동 닫기 흐름의 최종 확인은 별도로 필요하다.
