# 앨범

하단 탐색: 사진 · 즐겨찾기 · 폴더 · 지도 · 앨범. 백업은 설정의 **백업 관리**에서 연다.

하단 탐색은 아이콘만 표시하고 접근성 이름·툴팁을 유지한다. 높이는 안전 영역을 제외하고 49px이다.

앨범 생성, 이름 변경, 삭제, 사진 추가·제거 및 사진 보기 지원.
생성 시 **직접 담기**(빈 앨범) 또는 **기간으로 담기**를 선택한다.
기간은 사용 기기의 현지 날짜 기준으로 시작일 00:00부터 종료일 23:59:59.999까지 포함한다.
서버는 생성 시점에 활성 보관함에서 해당 촬영 기간에 속한 모든 사진을
페이지 수 제한 없이 원자적으로 담는다. 이후 추가·제거할 수 있으며,
나중에 인덱싱한 사진을 계속 자동 추가하는 스마트 앨범은 아니다.
앨범 표지는 가장 최근 촬영한 사진이며, 사진은 최신순으로 표시한다.
사진 선택은 100장씩 더 불러오며 한 번에 최대 200장을 추가·제거한다.
이미 포함된 사진 추가는 중복 없이 처리한다.

앨범과 사진 연결은 서버 SQLite의 `albums`, `album_photos`에 저장된다.
Tailscale 로그인 계정별로 소유권을 검사하며 같은 계정의 기기에서 접근한다.
비활성 공유 폴더나 인덱스에서 사라진 사진은 표시·개수에서 제외한다.
앨범 삭제·사진 제거는 연결 정보만 지우고 NAS 원본은 변경하지 않는다.

- `GET/POST /api/albums`: 목록 / 생성 (`name`, 선택적 `from`·`to` epoch milliseconds 쌍)
- `GET/PATCH/DELETE /api/albums/:id`: 사진 목록 / 이름 변경 / 삭제
- `POST /api/albums/:id/photos`: `{ action: "add" | "remove", ids: [...] }`

이 변경은 프론트엔드와 서버를 함께 배포해야 한다. 현재 디자인 프리뷰는
`.local/ui-state`의 합성 사진과 별도 프리뷰 계정을 사용한다.
