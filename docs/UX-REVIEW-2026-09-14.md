# 사진 UX·UI 개선 — 2026-09-14

기존 Pretendard, 중립적인 다크 테마와 앱 아이콘을 유지했다. 사진 감상과 반복적인 탐색을 우선해 모바일 조작, 검색 복구, 뷰어, 상태 안내를 개선했다. 제품 디자인과 상호작용을 두 개의 독립적인 읽기 전용 검토로 점검한 뒤 반영했다.

## 반영한 개선

- 모바일에 사진·즐겨찾기·폴더·지도·백업 하단 탐색을 추가했다. 보관함 연결과 설정은 기존 메뉴에서 접근한다.
- 촬영일 필터를 펼쳐 사용하는 방식으로 바꾸고 시작일·종료일을 명시했다. 잘못된 날짜 순서로 요청하지 않으며 종료일 마지막 밀리초까지 포함한다.
- 검색어 지우기와 검색 조건 초기화를 제공한다. 주요 화면을 전환하면 이전 화면의 검색 및 날짜 조건을 해제한다.
- 모바일 사진 크기를 3열과 2열로 전환한다. 이전에는 두 크기 모두 2열이라 버튼을 눌러도 차이가 없었다.
- 메뉴, 새로고침, 사진 크기, 뷰어 주요 버튼을 모바일에서 44px로 확장했다. 뷰어 파일명과 작업 버튼을 두 줄로 나눠 파일명과 날짜의 가독성을 확보했다.
- 뷰어에 현재 사진 순서를 표시하고 좌우 스와이프를 추가했다. 수직·대각선 움직임과 확대 상태에서는 사진을 바꾸지 않는다. 이전·다음 사진이 없으면 버튼을 비활성화하고, 목록 끝 근처에서 다음 목록을 미리 요청한다. 지도에서 열린 사진이 현재 목록에 없을 때 엉뚱한 첫 사진으로 이동하지 않는다.
- 모바일 메뉴에 포커스 이동과 순환, Escape 닫기, 닫은 뒤 열기 버튼으로 포커스 복귀를 추가했다. 메뉴가 열려 있는 동안 본문은 비활성화한다.
- 로딩, 연결 실패, 검색 결과 없음, 빈 즐겨찾기, 연결된 빈 보관함, 처음 연결하는 상태를 구분한다. 폴더 목록은 별도의 로딩·실패·재시도 상태를 사용한다.
- 오래된 캐시 조회가 새 검색 결과를 덮어쓰지 않도록 요청 세대를 재확인한다.
- NAS 연결 입력 중에는 설정의 추가 버튼이 입력 폼을 닫아 버리지 않도록 했다. 파일 백업 선택 버튼에도 키보드 포커스를 표시한다.

## 확인 범위와 남은 작업

실제 NAS 원본과 운영 인증 정보를 사용하지 않았으며 배포, Android APK 재생성 및 실기기 검증은 수행하지 않았다. 스와이프 판정은 자동 테스트로 검증했지만 실제 기기의 제스처 감각, TalkBack 및 사진 수가 많은 실제 보관함에서의 체감 성능은 실기기에서 추가 확인해야 한다. 전문 앱과 동등한 전체 기능이나 품질 인증을 의미하지 않는다.

기존 Impeccable 문맥에서 웹/Android 플랫폼 기록, DESIGN.md 보조 스키마와 빌드 방식 설정의 불일치도 발견됐다. 이번 인터페이스 개선과 분리했으며, 원하면 `document` 및 플랫폼 문서 정리로 갱신할 수 있다.
