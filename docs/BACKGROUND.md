# 백그라운드 처리

NAS 인덱싱과 썸네일·동영상 재생본 생성은 서버의 `photo.service`가 수행합니다. 앱·브라우저가 닫혀 있어도 시작 시와 5분 간격으로 연결된 폴더를 스캔하고, 실패한 변환은 시간당 다시 시도합니다. 활성 스캔은 중복 시작하지 않습니다. 서버 재시작 후 파일별 완료 캐시에서 이어갑니다.

선택한 폴더 아래의 중첩 폴더를 깊이 제한 없이 탐색합니다. 점으로 시작하는 숨김 파일·폴더와 심볼릭 링크는 제외합니다. 원격 폴더 접근 실패 시 기존 인덱스를 보존합니다. 원본 삭제는 정상적으로 전체 탐색을 마친 경우에만 인덱스에 반영합니다.

Android 자동 백업은 사진·동영상 권한, 백업 폴더, 네트워크 설정을 사용합니다. 즉시 작업과 15분 주기 WorkManager 작업을 예약하며, 실행 중 알림을 표시합니다. 한 작업은 약 8분 단위로 백업하고 남은 항목은 후속 작업에서 이어갑니다. 전송 실패·프로세스 종료 후에는 서버에 저장된 청크 위치와 완료 장부로 재개합니다. 앱을 열면 백그라운드 WebView를 정리하여 전경 작업과 중복하지 않습니다.

새 APK 설치 후 사진·동영상 접근 권한과 자동 백업 설정을 확인하세요. Android 13 이상에서는 알림 권한을 요청합니다. 알림을 거절해도 가능한 범위에서 백업하지만 알림 서랍에 진행 상태가 보이지 않을 수 있습니다.

Android 절전, 제조사 정책, 네트워크, 시스템 실행 할당량 때문에 실행 시점과 지속 시간을 보장할 수 없습니다. 설정에서 앱을 강제 종료하면 다시 열어야 예약 작업이 재개됩니다. 일반 웹 탭의 수동 업로드는 탭이 닫히면 중단되며, 같은 파일을 다시 선택하면 이어서 전송합니다. iOS 자동 백업은 제공하지 않습니다.


## 자동 갱신 복구 (2026-09-15)

Android는 저장된 활성화 상태를 기준으로 WorkManager의 15분 주기 작업을 유지합니다. 재부팅과 APK 교체 시 수신기가 주기 작업과 단발 작업을 다시 예약하며 중복 예약을 막습니다. 로그아웃 또는 자동 갱신 해제 상태는 복구 과정에서 다시 활성화하지 않습니다. 네트워크 제약과 실패 시 지수 백오프를 유지합니다.

자동 연결은 인증 창을 열지 않습니다. 연결 대기가 45초를 넘으면 대기·구독을 취소하고 멈춘 통신 엔진을 정리하여 다음 시도에서 새 연결을 만듭니다. 재인증이 필요한 경우 작업 결과를 auth로 남기며 성공으로 기록하지 않습니다. 화면 복귀, 네트워크 복구, pageshow와 기존 주기 갱신도 자동 연결 복구를 사용합니다. Android의 숨겨진 화면은 별도 백그라운드 작업과 중복 동기화하지 않습니다.

최근 앱 목록에서 닫거나 프로세스가 종료되어도 Android가 예약 작업을 실행할 수 있지만, 절전 정책에 따라 15분보다 늦어질 수 있습니다. 설정의 강제 종료는 다시 앱을 열 때까지 실행을 막습니다. 웹은 탭·브라우저 종료 후 기기 동기화를 보장하지 않으며 다시 열거나 연결이 복구되면 갱신합니다.

검증: 웹 빌드 및 자동 연결 복구·headless runner 회귀 테스트 통과. Android debug 앱과 instrumentation APK 빌드 통과. Android 16 임시 에뮬레이터에서 Activity 없이 번들 작업 실행, 미설정 계정 건너뛰기, 중복 없는 예약 및 boot/update 복구 경로를 검증했습니다. 실제 재부팅 주기, 제조사별 절전 상태와 실계정 장시간 전송은 이번 테스트 범위에 포함하지 않았습니다. 배포용 APK와 운영 웹은 별도 배포가 필요합니다.
