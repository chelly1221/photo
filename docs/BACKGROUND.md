# 백그라운드 처리

NAS 인덱싱과 썸네일·동영상 재생본 생성은 서버의 `photo.service`가 수행합니다. 앱·브라우저가 닫혀 있어도 시작 시와 5분 간격으로 연결된 폴더를 스캔하고, 실패한 변환은 시간당 다시 시도합니다. 활성 스캔은 중복 시작하지 않습니다. 서버 재시작 후 파일별 완료 캐시에서 이어갑니다.

선택한 폴더 아래의 중첩 폴더를 깊이 제한 없이 탐색합니다. 점으로 시작하는 숨김 파일·폴더와 심볼릭 링크는 제외합니다. 원격 폴더 접근 실패 시 기존 인덱스를 보존합니다. 원본 삭제는 정상적으로 전체 탐색을 마친 경우에만 인덱스에 반영합니다.

Android 자동 백업은 사진·동영상 권한, 백업 폴더, 네트워크 설정을 사용합니다. 즉시 작업과 15분 주기 WorkManager 작업을 예약하며, 실행 중 알림을 표시합니다. 한 작업은 약 8분 단위로 백업하고 남은 항목은 후속 작업에서 이어갑니다. 전송 실패·프로세스 종료 후에는 서버에 저장된 청크 위치와 완료 장부로 재개합니다. 앱을 열면 백그라운드 WebView를 정리하여 전경 작업과 중복하지 않습니다.

새 APK 설치 후 사진·동영상 접근 권한과 자동 백업 설정을 확인하세요. Android 13 이상에서는 알림 권한을 요청합니다. 알림을 거절해도 가능한 범위에서 백업하지만 알림 서랍에 진행 상태가 보이지 않을 수 있습니다.

Android 절전, 제조사 정책, 네트워크, 시스템 실행 할당량 때문에 실행 시점과 지속 시간을 보장할 수 없습니다. 설정에서 앱을 강제 종료하면 다시 열어야 예약 작업이 재개됩니다. 일반 웹 탭의 수동 업로드는 탭이 닫히면 중단되며, 같은 파일을 다시 선택하면 이어서 전송합니다. iOS 자동 백업은 제공하지 않습니다.
