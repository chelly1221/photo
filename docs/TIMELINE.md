# 연표 탐색

사진 목록 왼쪽 끝에 4px 폭의 짧은 흰색 세로 필만 표시한다. 배경 트랙, 월 숫자와 눈금은 없다. 평소에는 숨겨져 있고 스크롤할 때 360ms 동안 페이드인하며, 마지막 스크롤 또는 드래그 종료 후 1.1초가 지나면 260ms 동안 페이드아웃한다. 그리드 폭과 위치는 표시 여부에 따라 바뀌지 않는다.

바를 누르거나 드래그하면 오른쪽에 연·월이 나타난다. 누르고 있는 동안에는 계속 표시되며 손을 떼면 연·월이 접힌다. 터치 영역은 44px로 유지하며, 포인터 캡처로 손가락이 바 밖으로 나가도 드래그가 이어진다. 위·아래 끝에서는 첫 달과 마지막 달에 고정한다.

키보드 포커스가 들어오면 숨김 상태에서도 바와 연·월을 표시한다. 방향키는 한 달, PageUp/PageDown은 최대 12개 월 항목, Home/End는 처음과 끝으로 이동한다. Escape는 확장을 접는다. 모션 감소 설정을 따른다. 사진 목록의 오른쪽 기본 스크롤바는 숨겼으며 휠·터치 스크롤은 유지한다.

현재 검색어, 보관함, 폴더, 즐겨찾기, 날짜 범위와 정렬을 그대로 적용한다. 최신순에서는 아래로 갈수록 과거로, 오래된순에서는 아래로 갈수록 최근으로 이동한다. 마지막 월의 사진이 화면 높이보다 적더라도 선택한 연·월 표시를 유지하며, 사용자가 다시 스크롤하면 화면 위치에 맞춰 표시한다.

## 구현

- 인증된 `/api/timeline`에서 월별 개수와 정렬된 사진 목록상의 시작 offset을 계산한다. `/api/photos`와 필터 조건을 공유하며 비활성 보관함은 제외한다.
- 브라우저의 UTC 오프셋(분)을 전달해 월 경계를 계산한다. 한국 시간 UTC+9를 검증했다. 현재 오프셋을 사용하므로 서머타임을 적용하는 지역의 과거 월 경계를 위한 IANA 시간대 변환은 별도로 구현하지 않았다.
- 전체 사진 수를 기반으로 스크롤 공간을 만들고, 멀리 이동하면 해당 위치의 120장 단위 페이지를 요청한다. 앞선 페이지를 전부 다운로드하지 않는다. 스크롤 중 이동 요청은 100ms 지연으로 모으며 화면 주변만 렌더링한다.
- 날짜 위치를 불러오는 동안 자리표시자를 보여준다. 요청 세대로 오래된 응답을 차단하며 실패 시 해당 위치를 다시 요청한다. 오프라인에서는 캐시로 불러온 사진만 탐색하고 연표 이동 제한을 안내한다.
- 기존 NAS 원본·썸네일 생성·인증 방식은 유지한다. 이 기능을 운영에 적용하려면 프런트엔드와 API 서버를 함께 업데이트해야 한다.

## 검증 — 2026-09-14

- 웹 및 서버 빌드 통과. 월 숫자 필 수정 후 웹 빌드 및 테스트 28개 통과. 짧은 목록 전체 월 표시, 여러 해의 목록에서 선택 월 주변 간격, 빈 목록·단일 월 처리를 검증했다.
- 월 경계, 역순 offset, 검색·폴더·보관함·즐겨찾기 필터, 비활성 보관함 제외, 비인증 요청 거부, 타임존 입력 범위를 검증했다.
- 396장의 로컬 합성 검증 데이터로 모바일에서 2024년 6월 및 2023년 1월 이동, 첫 페이지 이후 사진 로딩, 세로 막대의 End 키 이동을 확인했다. 390px와 1280px에서 가로 넘침이 없으며 오래된순에서도 연표 순서가 반전되는 것을 확인했다.
- Impeccable 검사 결과는 문서·팔레트·타입 관련 advisory 39개다. 사용자 요청에 따른 긴 필 모양을 적용했다.
- 왼쪽 바의 최초 opacity 0, 스크롤 직후 표시, 실제 포인터 드래그로 2023년 10월 이동, 비활성 후 opacity 0 및 pointer-events none, 키보드 확장 표시를 브라우저에서 확인했다. 터치 좌표의 위·중간·아래, 바깥 영역, 한 달만 있는 목록, 짧은 화면 높이를 회귀 테스트에 포함했다.
- 최신 스크린샷은 `.impeccable/review/timeline-pill-mobile.png` 및 `timeline-pill-desktop.png`. 단색 이미지는 합성 검증 데이터이며 실제 개인 사진이 아니다.
