# 사진 배열 핀치

갤러리에서 두 손가락을 벌리면 사진이 커지고, 오므리면 작아지며 한 줄에 1~6장을 표시한다. 시작할 때 손가락 중간에 있던 사진과 사진 내부의 세로 위치를 기준으로 스크롤을 보정한다. 목록 처음과 끝에서는 스크롤 범위 안으로 제한한다. 사진 크기는 단계적으로 바뀌며 손떨림에 의한 단계 왕복을 막는다.

한 손가락 스크롤은 브라우저에 맡기고 두 손가락 입력만 직접 처리한다. 두 손가락 동작 중 페이지 확대를 막으며, 한 손가락을 먼저 떼거나 터치가 취소되어도 사진이 잘못 열리지 않게 한다. 키보드로 사진을 여는 동작은 차단하지 않는다. 조절 중에만 ‘한 줄에 N장’을 표시하고 종료 후 0.95초 뒤 페이드아웃한다.

상단 배열 선택 버튼은 사용자 요청으로 제거했다. 자동 배열은 모바일 3열, 넓은 화면은 폭에 맞춰 2~6열이며 핀치로 조절한다. 현재 배열은 화면 이동 중 유지하고, X로 기본 화면에 돌아가거나 앱을 새로 시작하면 자동으로 돌아간다. 배열 변경 결과는 화면 읽기 프로그램에도 알린다.

## 검증

- 웹 빌드와 테스트 32개 통과. 핀치 방향, 1~6열 제한, 경계 부근 손떨림, 중심 사진 위치 보존, 목록 처음·끝 보정을 검증했다.
- 로컬 합성 사진 396장으로 모바일와 데스크톱의 배열 선택, 중간 위치에서 사진 유지, 가로 넘침 여부를 확인했다.
- 브라우저 검증 도구는 두 손가락 입력을 지원하지 않는다. 실제 Android 터치 감도, 한 손가락 스크롤에서 핀치로 전환, 시스템 제스처 취소는 실기기 검증이 남아 있다.
- 2026-09-14 웹·API와 서명 APK 0.3.0을 운영에 배포했다. 공개 다운로드와 빌드 파일 일치 검증은 `VERIFICATION.md`에 기록했다.
